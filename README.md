# TÜRKİYE CUMHURİYETİ ÇAYDANLIK KAYNAMA REFERANDUMU
## ISO-KAYNAMA-100 / Resmî Buhar Protokolü 2026

Bu yazılım, mutfaktaki çaydanlığın 100 dereceye ulaştığı anda **kendi anayasasını** halk oylamasına sunmasını sağlar.

Sandık gözetmeni: buhar.
Mühür: ıslak kapak.
İtiraz makamı: altın gün çayı.

### Neden var?
Çünkü suyun kaynaması teknik bir olay değildir. Anayasal bir olaydır. 99 derecede henüz demokrasi yoktur. 100 derecede millet iradesi fışkırır.

### Kurulum

```bash
python3 referandum.py
```

Bağımlılık yoktur. Çünkü kaynayan su bağımsızdır.

### Kullanım

Program sizi milletvekili yapmaz. Sizi **su tanığı** yapar. Sıcaklık, basınç ve çay türüne göre evet/hayır oranı üretir. Sonuç her zaman geçerlidir çünkü itiraz edenler parmaklarını yakar.

### Anayasa Maddeleri (kısa özet)

1. Çaydanlık kaynamadan çay içilmez.
2. Kapak açılmadan oy sayılmaz.
3. Düdük, ulusal marşın kısa versiyonudur.
4. Soğuyan su yeniden seçime gider.

### Uyarı

Bu proje bilimsel değildir. Resmî durur. Çalışır. Kimseyi doyurmaz ama herkesi ısıtır.
